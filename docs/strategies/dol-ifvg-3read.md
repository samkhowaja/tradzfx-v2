# Draw on Liquidity + iFVG 3-Read System

**Source**: YouTube strategy transcript (video strategy — trader name unknown)
**Date extracted**: 2026-07-21

## Core Philosophy

"The real edge isn't your entry model or number of confluences — it's the destination. Where price is actually going."

**Difference**: Pattern trader vs Probability trader. Read the chart first, entry is last check.

## The 3 Reads (always in order)

### 1. Context (HTF Big Picture)

Where is price right now?

- **HTF Fair Value Gaps**: Mark 1h/4h/daily FVGs. Has price respected them, inverted them, or still trading inside?
  - Inside bullish FVG → look for longs
  - Inside bearish FVG → look for shorts
  - Never long inside bearish gap or short inside bullish gap (longing into resistance, shorting into support)
- **Market Structure**: Making HH/HL (bullish) or LH/LL (bearish)? Structure and FVGs should agree.
- **Big Picture Bias**: At all-time highs? Range lows? Middle of range?
  - At ATH → 99% only longs. Don't short ATH.

### 2. Draw on Liquidity (DOL = Target)

Where does price want to go? Obvious target above/below. These act as magnets for the algorithm.

**Types of DOLs**:

| Type | Description | Strength |
|------|-------------|----------|
| **Relative Equal Highs/Lows (EQH/EQL)** | Two highs/lows at same level → liquidity pool beyond | Strongest DOL |
| **Low Resistance Liquidity (Trend Line)** | Series of unswept highs/lows forming trend line | Strong (~90% chance of run) |
| **Previous Session High/Low** | Asian/London/NY session high/low left untapped by prior session | Moderate |
| **Protected High/Low** | After liquidity is taken at a level → becomes protected, no longer a DOL | Use as BE level |
| **Weekly Opening Gap** | Friday close to Sunday open gap (Sunday night/Monday only) | Short-lived |

**Key concept**: If there are no DOLs in one direction, price is unlikely to go there. "If you're bullish, what are you going to target?"

### 3. Alignment

Context and DOL must agree.

- **Bullish context + DOLs above** → trade is on the table (wait for entry)
- **Bullish context + all DOLs taken/below** → no trade, skip
- **Bearish context + DOLs below** → trade on table
- **Bearish context + all DOLs taken/above** → no trade

"If the context and DOL agree, the trade is on the table. If they don't, just skip."

## Entry Model

**V-shape Inverse FVG (iFVG)** — both reversals and continuations.

The entry is a **downstream of the read**. Wait for:
1. Liquidity sweep (price runs the DOL)
2. V-shape iFVG forms
3. Enter on iFVG confirmation

"Any entry mechanism works towards an aligned DOL. V-shape iFVG, MSS, CISD — all can work if you have aligned DOL with HTF context."

## Framework Rules

1. **Context first, DOL second, Alignment third, Entry last**
2. **No alignment = no trade** — even if entry pattern appears
3. **Skipping is OK** — 3 trades/week is fine
4. **DOL must exist before entry forms** — don't take trade and hope for target
